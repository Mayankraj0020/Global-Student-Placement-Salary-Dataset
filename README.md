# 🌍 Global Student Placement & Salary Dashboard

An interactive Power BI dashboard designed to analyze student placement outcomes, salary trends, college tiers, internships, countries, university rankings, and other key factors influencing placement performance.

## 📊 Dashboard Preview

![Dashboard Overview](Dashboard%20overview.png)

## 🎯 Project Objective

The objective of this project is to transform student placement data into meaningful insights using Power BI.

The dashboard helps explore placement outcomes and understand how factors such as academic performance, internships, college tier, university ranking, aptitude, communication skills, specialization, and industry are associated with placement and salary outcomes.

## 🛠️ Tools & Technologies

- Power BI

- Interactive Dashboard Design

## 📌 Key Features

- Interactive placement analysis
